HerdrChat

Your coding agents, as a chat on your phone.

HerdrChat connects over SSH to a machine you own — normally across a private network like Tailscale — and shows each herdr workspace running Claude Code as a conversation. You read what the agent did, answer when it is blocked, and send it back to work.

How it is built

  • No account and no server. There is nothing to sign into and no service of ours in the path.
  • It reads the transcript, not the terminal. Bubbles come from Claude Code's own session files, which is why they are clean.
  • Credentials stay in the Keychain, and host keys are pinned the first time you connect.

Status
