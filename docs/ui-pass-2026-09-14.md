# UI quality pass, 2026-09-14

Baseline: `282dceb`, Expo app version 0.7.9, build 56. Tested on a fresh
iPhone 17 Pro simulator running iOS 26.5, with the Mac's real herdr over SSH.
Only disposable `ui-pass-primary` and `ui-pass-secondary` conversations in
`~/Developer/apptest` were used for messages. A third, `ui-pass-from-phone`,
was created through the app. Existing workspaces were not prompted.

No version bump, native release, APK build, TestFlight upload or website deploy.
`socket.ts`, `events.ts` and `client.ts` are unchanged.

## Fixed

- [`3f89f0d`](https://github.com/cobanov/herdrchat/commit/3f89f0d): Bind the
  cached transcript to a live session before displaying it. A route previously
  seeded the workspace cache with no session identity, so a recycled workspace
  could briefly show a previous chat. Thread routes are now keyed by host and
  workspace, and the route delegates to `features/thread/ThreadScreen.tsx`.
- [`3f89f0d`](https://github.com/cobanov/herdrchat/commit/3f89f0d): Separate
  loading, waiting for a session, missing integration and no running agent.
  Sending into a plain shell is disabled. Reload clears this workspace's byte
  cursors and requests a refresh immediately instead of waiting for the 30 s
  safety poll. Reserve tail ownership before asynchronous setup and prevent an
  old tail from removing its replacement. Serialize older-history requests.
- [`3f89f0d`](https://github.com/cobanov/herdrchat/commit/3f89f0d): Keep the
  list's native initial bottom anchor, restore it on foreground/focus, and
  maintain it across viewport resizing while the reader is at the bottom.
  Remove the effect-body state update used to measure scroll position.
- [`210e6e2`](https://github.com/cobanov/herdrchat/commit/210e6e2): A completion
  event refreshes an idle chat's preview immediately. Previously the preview
  could wait for every fifth poll even after the host announced a completed
  turn. Stream liveness no longer tears down the poll loop; a request completing
  after cleanup cannot start another timer chain. Regression tests cover both
  list and thread lifecycle cases.
- [`d992b53`](https://github.com/cobanov/herdrchat/commit/d992b53): Preserve
  connection error codes in the editor and give authentication, bad key,
  unreachable host, missing executable, PATH and stopped-server failures their
  corresponding recovery action. Reject invalid ports, ignore a test result
  after the form changes, show the returned herdr version, and add a connection
  test to Settings. The server route now delegates to a feature component.
- [`e69bbdf`](https://github.com/cobanov/herdrchat/commit/e69bbdf): Fix doubled
  Dynamic Type line spacing and a clipped composer placeholder. The old
  `Text.tsx` comment and source-regex test required manual multiplication, but
  RN 0.86's Fabric `RCTAttributedTextUtils.mm` already multiplies `lineHeight`
  by the effective font multiplier. The simulator reproduced the excessive
  spacing at `accessibility-large`; native scaling now applies once, and the
  composer reserves a scaled line plus padding. Display-size caps remain.
- [`e69bbdf`](https://github.com/cobanov/herdrchat/commit/e69bbdf): Preserve
  the starting number of Markdown lists. A real response with blank lines
  between numbered paragraphs rendered every item as `1.`. The failing parser
  test now passes. Message accessibility labels include the actual message
  text and a copy action, rather than only saying "Agent message".
- [`c5e3117`](https://github.com/cobanov/herdrchat/commit/c5e3117): Dismiss the
  setup keyboard on a form drag or authentication-method change, so switching
  from username entry to the taller private-key input does not leave the old
  keyboard over the next field.
- [`b5e6b01`](https://github.com/cobanov/herdrchat/commit/b5e6b01): A three-line
  draft covered the final message timestamp even with the keyboard avoider.
  Measure the overlay clearance as part of the list footer and re-anchor a
  pinned reader only after that new content height has been laid out. Repeated
  one-line to three-line resizing now keeps the whole final bubble clear.
- [`e00cd53`](https://github.com/cobanov/herdrchat/commit/e00cd53): Align the
  new Settings connection result with the existing row insets.
- [`8be13c6`](https://github.com/cobanov/herdrchat/commit/8be13c6): Keep long
  values inside Settings rows. The host's preview-version string extended
  beyond its card; the row now shrinks and middle-ellipsizes its value. The
  connection test above shows the full version on wrapped lines.
- [`9674235`](https://github.com/cobanov/herdrchat/commit/9674235): Repair
  Maestro's stale host label, overridden environment values, multiline key
  import, keyboard-obscured targets and unsupported timeout syntax. Match
  disposable chats by workspace ID. Add `thread-bottom` and the visually
  inspected `composer` regression fixture. Document raw-artifact secrecy.
- [`b30f895`](https://github.com/cobanov/herdrchat/commit/b30f895): A newly
  started agent may not create a transcript until its first prompt. The new
  loading state waited indefinitely for that file. Two failing hook tests
  pinned absent and unreadable transcript probes; both now end the spinner,
  keeping absence distinct from a read error. A real unprompted session now
  displays the ready empty state in both themes. Add `thread-empty` to Maestro.

## Found and left open

- Physical iPhone acceptance: the user's iPhone 14 Pro was connected over USB
  and paired, with Developer Mode enabled. Xcode could not mount its developer
  disk image because the device remained locked (`kAMDMobileImageMounterDeviceLocked`).
  No build was installed on the phone. Owner: device acceptance, after unlocking.
- A real network interruption and APNs delivery still need device acceptance.
  Lifecycle regression tests cover late responses after backgrounding; this is
  not evidence of recovering a dropped physical Tailscale connection. The Mac's
  shared herdr server was not stopped while other workspaces were active.
- Key generation is not implemented in the editor. It accepts a password or an
  existing OpenSSH private key. Owner: setup feature, if generation remains a
  product requirement. This pass imported the already-authorized test key.
- Host-key rotation, installer execution and starting a stopped real server
  were not forced on the shared host. Error classification and recovery
  dispatch have unit coverage; that does not establish end-to-end acceptance
  of each remote recovery action. Owner: isolated host test fixture.
- The complete remote-failure matrix still needs an isolated fixture:
  wrong password, unreachable address, missing herdr, missing PATH entry,
  stopped herdr, and rotated host key. This pass saw the malformed-key error
  and its specific recovery button during import testing, and a successful
  real connection afterward. Unit classification is not a substitute for
  executing every failure and recovery. Owner: connection acceptance.
- Prompt-history chips were deliberately removed earlier. The source comment
  records that choice; they were not reintroduced. Owner: product decision.
- The app is explicitly portrait-only in `app.json`. No orientation policy was
  changed to make a rotation test pass. Owner: product, if landscape is wanted.
- The previously documented idle event-stream cleanup limitation remains in
  `events.ts`. This pass did not alter transport ownership or CLI fallback.
- Further lifecycle cases to cover: a session rotating while an older-history
  request is in flight, and repeated identical optimistic prompts. Owner:
  thread state. Existing transcript deduplication is not proof of these cases.
- Destructive removal is not exercised against an existing user's host or
  workspace. Confirmation wording can be checked with disposable fixtures,
  but production deletion is outside this pass. Owner: isolated acceptance.
